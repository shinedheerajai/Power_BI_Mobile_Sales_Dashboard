# Mobile Sales Dashboard (Power BI)

An interactive, mobile-optimized Power BI dashboard designed to deliver comprehensive insights into mobile sales performance. This project tracks, visualizes, and analyzes retail data across multiple business dimensions to drive data-backed decisions.

## 📊 Project Overview
This project transforms raw transactional data into actionable business intelligence. It provides stakeholders with a holistic view of sales metrics, enabling them to dissect performance by geography, customer behavior, and product inventory over time.

## 🔑 Key Insights & Dimensions
The dashboard delivers deep analytical value across five primary areas:
* **Geography:** Pinpoint top-performing regions and city-level sales distribution.
* **Transactions:** Analyze customer payment preferences and revenue by transaction type.
* **Customer Feedback:** Correlation between product ratings and overall sales volume.
* **Inventory & Product:** Granular performance tracking broken down by mobile brand and specific models.
* **Timeline Analysis:** Historical sales trends, seasonality, and time-period growth metrics.

## 🛠️ Tech Stack & Tools
* **BI Platform:** Microsoft Power BI Desktop
* **Data Transformation:** Power Query (ETL process)
* **Data Modeling:** DAX (Data Analysis Expressions) for custom metrics and calculated columns

## 🚀 Getting Started

### Prerequisites
To view and interact with the local project file, you will need:
* [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/) (Free download)

### Installation & Usage
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/your-username/mobile-sales-dashboard.git
   ```
2. Navigate to the project directory and open the `.pbix` file.
3. Explore the interactive visual elements using the built-in slicers and filters.
